# Babylon Client

This is the client for the Babylon project, a React and TypeScript application.

## Getting Started

To get the client up and running, follow these steps:

1.  **Install Dependencies:** Navigate to the `client` directory and run the following command to install the required dependencies:
    ```shell
    npm install
    ```

2.  **Build the Application:** To build the React application, run the following command:
    ```shell
    npm run build
    ```

3.  **Start the Server:** To start the client server, run the following command:
    ```shell
    npm start
    ```

The client will be available at `http://localhost:3000`.

## Development

For development, you can use `npm run start:dev` to start the server with hot-reloading enabled.

## Testing

To run the tests, navigate to the `client` directory and run the following command:

```shell
npm test
```

This will run the Jest test suite.
